Tudo que você precisa saber
sobre WhatsApp API com a Neppo

O WhatsApp Business App é gratuito e serve para pequenas empresas com um único usuário. A WhatsApp Business API (ou API Oficial do Meta) é a solução para empresas que precisam de escala: permite múltiplos atendentes simultâneos, chatbot com IA, disparos em massa, relatórios e integração com sistemas como CRM e ERP. A Neppo é BSP (Business Solution Provider) certificado pelo Meta para fornecer acesso à API Oficial.
Sim — desde que seja pela API Oficial e com templates aprovados pelo Meta. O disparo em massa por aplicativos não-homologados viola os termos de serviço e pode resultar em banimento do número. Com a Neppo, todos os envios seguem as diretrizes do Meta: templates pré-aprovados, opt-in da base e limites de frequência respeitados.
Não. A Neppo opera exclusivamente com a API Oficial do Meta. Por ser um BSP certificado, todo o uso está dentro dos termos de serviço do WhatsApp. Isso elimina qualquer risco de banimento por uso da plataforma. O risco existe apenas com soluções que acessam o WhatsApp de forma não-oficial.
O processo de ativação da API Oficial envolve verificação do número e aprovação pela Meta. Com suporte da Neppo, esse processo geralmente leva de 24 a 72 horas úteis. Após a ativação, a configuração da plataforma e dos chatbots é feita com apoio do time de onboarding Neppo.
A Neppo tem integração nativa com o Sankhya ERP e o Ploomes CRM — não é uma conexão genérica via API, mas integrações desenvolvidas, homologadas e mantidas pela própria Neppo. Por fazer parte do ecossistema Sankhya desde 2021, empresas que já usam o Sankhya ou o Ploomes têm acesso a recursos como régua de cobrança, venda digital e chat embarcado direto no sistema que já usam no dia a dia. Para outros ERPs e CRMs, a Neppo disponibiliza uma API aberta, permitindo que sua equipe técnica ou parceiros desenvolvam a integração com o sistema que sua empresa já utiliza.
O Meta cobra por conversa (não por mensagem individual). As conversas são categorizadas em: marketing, utilidade, autenticação e serviço — cada uma com tabela de preços diferente. A Neppo detalha esses custos de forma transparente e ajuda a otimizar o uso para reduzir despesas com conversas desnecessárias. Fale com nosso time para uma simulação de custo para o seu volume.
Sim. A API Oficial permite usar o mesmo número para diferentes finalidades: atendimento receptivo (inbound), disparos de campanhas (outbound) e notificações automáticas (transacionais). A plataforma Neppo gerencia cada fluxo de forma separada, sem misturar atendimentos humanos com automações.
WhatsApp Voz (ou WhatsApp VoIP) é a funcionalidade que permite chamadas de áudio integradas ao fluxo de atendimento digital. Na Neppo, é possível escalar de uma conversa em texto para uma chamada de voz sem perder o histórico de mensagens e sem sair da plataforma. É um diferencial exclusivo da Neppo no Brasil, não encontrado em ferramentas internacionais ou nacionais concorrentes.
